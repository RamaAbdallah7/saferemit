One fraud decision from the signals only the network can see.

SafeRemit is an AI agent that fuses SIM-swap, device, roaming and location signals from CAMARA APIs into a single real-time verdict — stopping remittance account takeover and mule onboarding before the money moves, with zero added friction for everyone else.

The problem

Two fraud patterns own the MENA remittance corridor.

The GCC is the world's second-largest remittance-sending region (World Bank). Tens of millions of migrant workers send money home on a monthly cycle — a predictable, high-value flow that fraud rings target with two specific plays.

Pattern 01 — account takeover

SIM-swap interception

A fraudster ports the victim's number to a new SIM right before payday, intercepts the OTP, drains the account. The SMS one-time password — still the backbone of remittance auth — is exactly what the attack defeats.

Pattern 02 — synthetic onboarding

Mule-account creation

Rings open accounts remotely with stolen or fabricated identities, then use them to launder proceeds. Document-based KYC passes because the documents are real — they just don't belong to the person holding the phone.

Static OTP and document checks are point-in-time and self-reported. Neither can answer the questions that actually separate a legitimate remitter from a fraudster: was this SIM swapped an hour ago? Is the device really in the country it claims? Has the network ever seen this handset on this account?

How it works

An agent that decides which signal is worth pulling.

SafeRemit sits between a remittance app and its transaction pipeline. On every sensitive event it runs a small decision graph — not a fixed checklist — built on LangGraph, with Gemini as the analyst that reasons about the signal combination. Both are on the hackathon's approved tooling guide; the whole stack is the guide's recommended intermediate architecture.

  1. Cheap checks first, in parallel

    Number Verification and SIM Swap fire together — they only need the phone number. A clean result on a routine login ends here: no deeper calls, no cost, no latency.

  2. Escalate only on cause

    If the action is sensitive (onboarding, transfer) or an early signal already looks wrong, the agent pulls Device Status and Location Verification — also in parallel. This conditional branch is what makes it agentic rather than a linear pipeline.

  3. Two opinions, reconciled

    A transparent rules score fuses the signals into a 0–100 number. In parallel, Gemini reads the same signals and reasons about the combination — a lone SIM swap is noise, a SIM swap plus a new roaming device plus a transfer is a textbook takeover. The agent takes the stricter of the two verdicts and flags any disagreement for a human.

Technical status

Live calls, not a mock.

The prototype runs real requests against Nokia Network-as-Code on its simulated network. Three of the four CAMARA APIs execute live end-to-end; a full four-signal decision returns in about three seconds. Every call degrades to cached data on failure, so the demo never stalls.

Number Verification is CAMARA's 3-legged flow — the subscriber's device authorises on-network before the check. That belongs in the mobile app, not a server; it's wired and shown in the trace, and runs live in production where the redirect exists.

Business

A fraud-decision API, priced per decision.

B2B2C. SafeRemit licenses to remittance apps, mobile-money operators and banks as a decisioning endpoint — priced per decision or per account protected. It sits alongside existing KYC and rules engines, not in place of them, so integration is a single API call at three moments: login, onboarding, transfer.

Why now

GSMA Open Gateway is making CAMARA APIs commercially available across MENA operators for the first time. The network signal exists; nobody is orchestrating it into a product-grade fraud verdict yet.

Where it goes next

The same orchestration pattern — fuse weak network signals into one high-confidence call — generalises directly to telecom fraud, insurance-claim validation and e-commerce account takeover.

Where it stands

Idea shortlisted. Prototype already calling the network.

Public repository, automated test suite, live CAMARA integration, and an agent whose reasoning you can watch step by step. The prototype phase is for hardening the mobile consent flow, scripting the live demo, and the pitch.
