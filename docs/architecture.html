SafeRemit · system architecture

Actors and components

SafeRemit is a single decisioning service the enterprise calls. It orchestrates the CAMARA APIs and an LLM as data sources; a deterministic rules engine owns the score, and reconcile owns the final call.

SafeRemit · the LLM, the score, and scale

How the AI is controlled — and how this scales

The AI is a second opinion, not the decision-maker. The rules engine is transparent and auditable; the AI can only make a call stricter.

The LLM — controlled, not trusted blindly

  • Model: Google Gemini (gemini-3.6-flash) via Google AI Studio — a general model, not fine-tuned.
  • Output control: constrained to a fixed JSON schema {decision, risk_score, reasoning}; temperature 0.2; small thinking budget; the response is validated before it is used.
  • Authority: advisory. It can raise the severity of a decision, never lower it. The deterministic rules score is the floor.
  • Failure: if Gemini errors or is unconfigured, the agent proceeds on the rules score alone. A rules-vs-AI disagreement is flagged for a human.
  • Runs when: escalation path only — a clean login never calls it.

Scale & extensibility

  • Stateless per-decision API — scales horizontally, no session state.
  • Latency: ~sub-second on the clean fast path; ~2–3 s on the full escalated path (network calls + LLM run in parallel).
  • New signals plug into the same points table without touching orchestration logic.
  • New corridors / operators: one GSMA Open Gateway integration, no per-bank rebuild.
  • Same pattern generalises: fuse weak network signals into one high-confidence verdict → telecom fraud, insurance-claim validation, e-commerce account takeover.

The rules engine — deterministic points table (0–100)

SIM swapped within 72 h+45
Number not verified on the device+35
Claimed location doesn't match the network+30
  ↳ but the device is roaming — scored as likely travel+15
Device never seen on this account+20
Device is roaming+10
Claimed location partially matches+15
ALLOW  0 – 29 STEP-UP  30 – 69 BLOCK  70+
No single signal can block. The largest single score is +45 — a BLOCK needs 70, so it always takes at least two corroborating signals. A VPN, travel, or a lone location mismatch lands in STEP-UP (extra verification), never an outright BLOCK.
