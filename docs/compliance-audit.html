Scope control

The Tooling Guide's first tip: "Pick one focus area on day one and resist scope creep — judges prefer one polished agent over five half-built ones." SafeRemit is already inside that line. Nothing below asks for a new feature — the remaining work is packaging.

Locked scope — do not widen before 2026-09-13

Source: Resource & Tooling Guide §11 · §10 "Intermediate stack (Python)"

One agent, one decision, one corridor. A LangGraph agent turns four CAMARA signals into a single ALLOW / STEP_UP / BLOCK verdict for a cross-border remittance event. Focus area: AI for fraud detection and digital identity.

In scope — finish these

  • 3-minute demo video
  • Pitch deck exported to PDF/PPT
  • Source-code zip (< 50 MB)
  • 3–5 UI screenshots
  • Optional: one free-tier deployment for the Demo Link

Out of scope — resist

  • Number Verification 3-legged OAuth / device consent flow
  • A companion mobile app
  • Real (non-simulator) SIM cards
  • Multi-corridor / multi-currency logic
  • Analytics dashboards, a second theme, more CAMARA APIs

Exceeds the "≥ 1" bar and the "Good-to-Have: multiple CAMARA APIs".

MetProblem Statement
· Build an AI Agent Layer

An AI agent layer orchestrates the APIs as real-time data sources, not user-triggered buttons

"…intelligently orchestrates one or more CAMARA APIs as trusted, real-time data sources rather than treating them as simple user-triggered actions" — must make intelligent decisions using network signals, automate workflows, power assistant/copilot experiences.

Evidencebackend/agent/orchestrator.py — a LangGraph StateGraph: parallel initial_checks (Number Verification + SIM Swap) → a conditional escalation edge (route_after_initial) → escalated_checks (Device Status + Location) → a Gemini reasoning node → finalize. The agent decides which API to call; the user never picks. Output is an automated ALLOW / STEP_UP / BLOCK decision with a reasoning trace.

No unlisted agent framework or model provider anywhere in backend/agent/. See §06 below for the full inventory.

StrongComplexity & Implementation

Technical depth, clear design, effective CAMARA use, feasible architecture, AI-agent design on approved tools

EvidenceLangGraph graph with a conditional branch and an LLM node; 4 CAMARA integrations; 29 tests; architecture diagram in the deck and README. The "approved tools" sub-clause is covered in §05.
