SafeRemit — Decision Reconciliation

Two independent verdicts, one honest decision

Every escalated request is scored twice — once by deterministic rules, once by an LLM reading the same signals. The system never lets the AI silently override the rules, or vice versa.

Deterministic
Rules score
Fixed point weights per signal (SIM swap, roaming, location mismatch, unknown device) summed to 0–100. Same input, same output, every time.
+
Google AI Studio
Gemini verdict
Reads the same signals plus context, returns its own decision and a plain-language reason. Runs only on the escalation path.
Reconciliation rule
The stricter of the two verdicts wins. If they disagree, the result is flagged — never silently smoothed over — and the reasoning trace shows both.
